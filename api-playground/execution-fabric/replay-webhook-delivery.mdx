Production partner preview. The gateway checks runs:write; the backend reauthorizes both runs:read and runs:write, so the key must carry both scopes. Send an exact empty JSON object.

<Info>
  **Availability:** Partner preview. **Required scopes:** `runs:write`, `runs:read`.
</Info>

Use a disposable personal workspace key and verify the returned resource or receipt before treating the operation as complete.
