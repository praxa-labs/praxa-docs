Production partner preview. The gateway checks runs:write; the backend reauthorizes both runs:read and runs:write, so the key must carry both scopes. Deletion disables the endpoint and returns no body.

<Info>
  **Availability:** Partner preview. **Required scopes:** `runs:write`, `runs:read`.
</Info>

Use a disposable personal workspace key and verify the returned resource or receipt before treating the operation as complete.

## Request fields

<ParamField path="endpointId" type="string" required>
  endpointId path parameter.
</ParamField>

## Successful response

**204** — Endpoint disabled.

<RequestExample>
~~~bash cURL
curl --fail-with-body -X DELETE 'https://api.praxa.io/v1/webhooks/endpoint-demo-0001' \
  -H "Authorization: Bearer $PRAXA_API_KEY"
~~~
</RequestExample>
