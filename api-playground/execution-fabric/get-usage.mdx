<Info>
  **Availability:** Production partner preview. **Required scope:** `usage:read`.

Use a disposable personal workspace key and verify the returned resource or receipt before treating the operation as complete.

## Request fields

<ParamField query="from" type="string" required>
  Inclusive RFC 3339 range start.
</ParamField>

<ParamField query="to" type="string" required>
  Exclusive RFC 3339 range end. It must be after from; the management implementation accepts a maximum range of 366 days.
</ParamField>

<ParamField query="group_by" type="hour | day | month">
