Requires a personal workspace key with memory:write and a stable Idempotency-Key. Identity and tenant are derived from the key. The candidate remains isolated from first-party Praxa memory planes.

<Info>
  **Availability:** Qualification preview. **Required scope:** `memory:write`.
</Info>

Use a disposable personal workspace key and verify the returned resource or receipt before treating the operation as complete.
