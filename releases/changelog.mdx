## Version 0.3.0

- Published <code>@praxa/sdk</code>, <code>@praxa/cli</code>, and <code>@praxa/mcp-contracts</code>.
- Added the dependency-free <code>@praxa/sdk/memory</code> entrypoint.
- Added read-only adapters for Mem0, LangGraph, Zep, Graphiti, Letta, and OpenAI Agents.
- Added local CLI memory-source and sync-plan commands.
- Preserved established Aura-compatible Gateway and MCP wire identifiers.

## Documentation expansion

- Added outcome-based use cases and end-to-end tutorials.
- Added interactive Execution Fabric and hosted-memory API Playground sections.
- Added a public Capability Atlas and Praxa product guide families.
- Added visual architecture, lifecycle, retry, event, webhook, memory, and evidence diagrams.
- Added operations, troubleshooting, compatibility, migration, and deprecation guides.
- Added chart-first rendering of the pinned public benchmark evidence.
