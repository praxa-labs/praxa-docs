Create recurring work, monitor conditions, plan longer goals, and inspect proactive results.

<Note>
Scheduling a job defines future work; it does not pre-authorize every external effect that work may propose.
</Note>

## Provided capabilities

| Capability | Status | Surfaces | Who it helps |
|---|---|---|---|
| **Scheduled automations**<br />Create recurring agent jobs such as digests and follow-up workflows. | Live | iOS, web | Individual, Business, Team |
| **Monitors and watches**<br />Watch web pages, prices, or conditions and notify when the condition changes. | Live | iOS, web | Individual, Business, Team |
| **Missions and plans**<br />Break a longer goal into an explicit plan with visible steps and bounded execution. | Live | iOS, web | Individual, Business, Team |
| **Plan feasibility**<br />Check whether a plan fits available time using explicit arithmetic and constraints. | Live | iOS, web | Individual, Business |
| **Daily briefing and proactive greeting**<br />Assemble a day-start view from relevant calendar, task, and follow-up information. | Live | iOS, web | Individual, Business |
| **Push and smart notifications**<br />Deliver automation results, monitor triggers, and team activity through configured notifications. | Live | iOS, web | Individual, Business, Team |

## Example outcomes

1. **Schedule a digest.** Create a recurring digest with an explicit schedule, source scope, and delivery destination.
2. **Monitor a condition.** Watch a price or page condition and verify a notification is emitted only when the condition is met.
3. **Check plan feasibility.** Give Praxa a set of tasks and time constraints and inspect the arithmetic behind the answer.
4. **Review a daily briefing.** Open the day-start brief and follow each item back to its current calendar, task, or message source.
