> **Status:** The public partner preview supports a narrow personal-tenant
> boundary: tenant API keys, minimal durable task execution, run reads,
> resumable SSE, cooperative cancellation, usage readback, and automatic signed
> webhooks. Exact browser approval remains pending. Production canaries have
> proved both cancellation final-state branches. Turn mode, request overrides,
> organization execution, and mature receipts are unavailable.

These guides separate what you can call today from the larger product direction.
The existing custom-agent deployment surface uses a different credential and
execution product; it remains available and is not replaced by `praxa_sk_`.

## What works today

1. Submit a strict `mode:"task"` request with only an input.
2. Receive a UUID `run_id` and follow its lifecycle through a run read or SSE.
3. Cancel cooperatively when necessary and wait for a real terminal state.
4. Read tenant-scoped usage backed by completed provider and settlement evidence.

The current public API does not accept caller-selected agents, context, tools,
policy, model lanes, delivery settings, or organization identity. It also does
not produce a mature policy/approval/verification receipt.

## Choose a guide

| If you want to... | Read | Current fit |
|---|---|---|

| Track a recurring internal task | [Business workflows](/fabric/use-cases/business-workflows) | Personal preview only; organization execution and generic committing-tool approvals are unavailable. |
