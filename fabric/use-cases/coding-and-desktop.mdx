> **Status:** Minimal personal-tenant durable execution is live for admitted
> partner-preview tenants. Praxa Control integration, automatic repo/context
> transfer, caller-selected tools, BYO provider routing, and turn mode are not
> public execution features.

A local Codex or Claude Code session and a Praxa cloud task are separate
systems. Starting a cloud task does not upload your repository or grant the
runtime access to local files unless a future capability explicitly does so.

From a trusted local script or backend, submit only the supported envelope:

```http
POST /v1/execute
Authorization: Bearer praxa_sk_...
Content-Type: application/json
X-AI-Platform-Version: v1
Idempotency-Key: rn-084-impact-2026-08-01

{
  "apiVersion": "v1",
  "requestId": "rn-084-impact-2026-08-01",
  "mode": "task",
  "task": {
    "input": "Produce a migration checklist for upgrading React Native 0.83 to 0.84 using only information available to the cloud task."
  },
  "idempotencyKey": "rn-084-impact-2026-08-01"
}
```

Do not add `context`, `tools`, `policy`, `delivery`, or `task.agentId`; the
current handler rejects them. A successful response contains a UUID `run_id`:

```json
{
  "apiVersion": "v1",
  "run_id": "2f47a86e-72ce-4f27-8ff0-7dc0c959fd35",
  "requestId": "rn-084-impact-2026-08-01",
  "mode": "task",
  "status": "queued",
  "createdAt": "2026-08-01T12:00:00.000Z",
  "updatedAt": "2026-08-01T12:00:00.000Z",
  "links": {
    "self": "/v1/runs/2f47a86e-72ce-4f27-8ff0-7dc0c959fd35",
    "events": "/v1/runs/2f47a86e-72ce-4f27-8ff0-7dc0c959fd35/events"
  }
}
```

Poll the run, resume its SSE feed with `Last-Event-ID`, or configure an automatic
signed webhook. The cloud task continues independently of the laptop; the
webhook notifies your server and does not execute work on the closed device.

The cloud task uses Praxa's bundled execution supply. It does not proxy the
local coding session's provider credentials. BYO funding is planned, not live.
